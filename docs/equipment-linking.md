# 설비별 링킹(🔗) 동작

현재 구현 기준 (`src/types/links.ts`, `LinkGuide`, `FactorySimulator`, `PalletCycle`).  
편집 모드에서 도구 **연결(L)** 로 설비를 이으면 관계가 생기고, **연결이 없으면** 거리·셀 기반 폴백이 동작한다. 장면의 `autoConnect`가 꺼져 있으면 폴백 없이 링크만 사용한다.

## 1. 공통 규칙

| 항목 | 내용 |
|---|---|
| 방향 | 대체로 **물류 흐름** 방향. 예외: `pickup`은 AMR → 팔레트 스테이션 |
| 저장 | `useSceneStore.links` / 템플릿 `links: { type, from, to }[]` (장비 **배열 인덱스**) |
| 로드 ID | 실행 시 `${kind}-${index+1}` (예: `amr-3`, `rack-78`) |
| AMR 위 팔레트 | `mountedOn` 팔레트는 링킹 UI·편집을 **탑재 AMR이 소유**. 시뮬은 팔레트 id의 `deliver` 등을 그대로 읽음 |
| 역할 분리 | `kind`는 모두 `amr`/`rack`이어도 `amrRole`·`rackType`에 따라 안내·방향이 달라짐 (포크리프트 / AGV / 출하 AMR / 이동식 랙) |
| 자동 방향 보정 | 지게차↔AMR `emptyReturn`, 지게차·AGV↔랙 `store`, 출하 AMR↔출하 컨베이어 `handoff`는 클릭 순서와 무관하게 올바른 방향으로 맞춤 |
| 역할 제약 | `src/domain/layout/linkConstraints.ts`: AGV→고정랙·deliver→지게차 등 금지. 역할/`rackType` 변경·템플릿 로드 시 무효 링크 제거 |

### 링크 타입

| type | 라벨 | from → to | 의미 |
|---|---|---|---|
| `feed` | 공급 | conveyor → robot / amr / scanner / rail | 컨베이어가 누구에게 물건을 넘기는지 |
| `load` | 적재 | robot → pallet | 로봇이 어느 팔레트에 쌓는지 |
| `pickup` | 픽업 | amr → pallet | 어느 AMR이 그 스테이션 팔레트를 싣는지 |
| `deliver` | 출고 | pallet → dock / rack / conveyor / robot / amr | 만재 팔레트 목적지 |
| `emptyReturn` | 교체·회수 | amr → amr(지게차) / dock | **만재 교체 담당** 지게차 + 빈 팔레트 회수(또는 적치장). 이름보다 범위가 넓음 |
| `store` | 담당 랙 | amr(지게차·AGV) → rack | 지게차: 고정·이동식 / **AGV: 이동식만** (`linkConstraints`) |
| `collect` | 빈 팔레트 회수 | transfer → amr(지게차) / dock | 리프트가 내린 빈 팔레트 회수 |
| `distribute` | 분배 | rail → transfer | 레일 끝에서 넘길 리프트 |
| `handoff` | 출하 | amr(출하) → conveyor | 출하 AMR이 밀어 넣을 출하 컨베이어 |

연결 불가: `floor`, `door` (및 규칙에 없는 쌍).

## 2. 설비별 동작

### 2.1 컨베이어 (`conveyor`)

| 링크 | 동작 |
|---|---|
| **공급 → 로봇** | 해당 라인 박스를 그 로봇이 집음. 없으면 reach·거리 폴백 |
| **공급 → AMR** | 입하/셔틀 등 그 AMR이 컨베이어와 상호작용 |
| **공급 → 스캐너** | 이 컨베이어 담당 AMR이 그 스캐너에서 하역 |
| **공급 → 레일** | 이 컨베이어 담당 AMR이 팔레트를 그 레일 중심에 올림 |
| **출고 ← 팔레트/AMR** | 만재 팔레트를 이 컨베이어로 받음 |
| **출하 ← 출하 AMR** | 출하 AMR이 팔레트를 이 벨트로 밀어 넣음 |

컨베이어끼리 이어붙이기는 링크 없이 끝점 스냅으로 유지. `feed`는 연결된 구간 전체에 적용.

### 2.2 로봇 (`robot`)

| 링크 | 동작 |
|---|---|
| **공급 ← 컨베이어** | 집는 박스 후보 컨베이어 제한 |
| **적재 → 팔레트(·AMR 위 팔레트)** | 적재 대상 스테이션. 없으면 reach 안 팔레트 폴백 |
| **출고 ← 팔레트/AMR** | 팔레트를 로봇(하역)으로 보내는 경로 |

### 2.3 팔레트 스테이션 (`pallet`)

| 링크 | 동작 |
|---|---|
| **적재 ← 로봇** | 누가 이 팔레트에 쌓는지 |
| **픽업 ← AMR/출하 AMR** | 누가 만재 후 싣고 가는지. 자동연결 off + 링크 없으면 출고 안 함 |
| **출고 → dock/rack/conveyor/robot/amr** | 목적지. 여러 개면 acceptGrade·enabled·빈자리 통과 후 **경로상 가까운** 곳. 자동연결 off + 링크 없으면 출고 안 함 |

AMR에 실린 팔레트는 디테일에서 “AMR에 실린 팔레트 → 캐리어 연결을 따름”으로만 표시.

### 2.4 팔레트 AMR / 셔틀 (`amr`, role ≠ forklift·agv·ship)

| 링크 | 동작 |
|---|---|
| **공급 ← 컨베이어** | 입하 벨트와 짝 |
| **적재 ← 로봇** | 적재 대기 위치·대상 |
| **픽업 → 팔레트** | 담당 스테이션 |
| **교체·회수 → 지게차** | 만재 교체·빈 회수 담당 지게차. **링크가 있으면 그 AMR만** 담당(미연결 AMR은 받지 않음) |
| **교체·회수 → 적치장** | 빈 팔레트 스택 |
| **출고 → …** | 탑재 팔레트의 `deliver`와 동일하게 보임·편집 |

**셔틀 + 지게차:** `emptyReturn`으로 연결된 지게차의 교체(stop) 독으로 만재 후 이동. 없으면 가까운 서비스 독.

### 2.5 포크리프트 (`amrRole: forklift`)

| 링크 | 동작 |
|---|---|
| **교체·회수 ← AMR** | 그 AMR만(또는 링크된 AMR 우선) 만재 교체·빈 회수 |
| **교체·회수 → 적치장** | 빈 팔레트 가져오기·쌓기 위치 |
| **담당 랙 → 이동식 랙** | `mobileRack` 작업 시 **연결된 Rack_m에만** 만재 적재. 없으면 같은 셀 Rack_m |
| **담당 랙 → 고정 랙** | 입고·출고 담당 랙. 있으면 그 랙만, 없으면 “아무 지게차에도 안 묶인 랙” 폴백 |
| **회수 ← 트랜스퍼** | 리프트가 내린 빈 팔레트 회수 |

작업(`forkliftTask`)과 링크 조합:

- `mobileRack`: 만재 AMR → Rack_m (`store` 이동식 우선)
- `rack`: Rack_m(하차점) → 고정 랙 (`store` 고정)
- `palletSwap`: 빈 공급·회수 (`emptyReturn`)
- `unload`: 하역 흐름 (캐리어)

### 2.6 AGV (`amrRole: agv`)

| 링크 | 동작 |
|---|---|
| **담당 랙 → 이동식 랙만** | 연결된 Rack_m만 견인(만재 → rackDrop, 비면 복귀). 연결 없으면 **같은 셀** Rack_m |

고정 랙과는 연결 자체가 거부된다.

**행동 준비(설정 패널 체크포인트):**

| 항목 | 필수? | 없으면 |
|---|---|---|
| **Rack_m 하차 위치** (`rackDrop` 정차) | **필수** | 만재 Rack_m을 옮기지 않음 |
| **경로 연결** (`agvPath`) | 권장 | 자동 경로로 운반 |
| **담당 Rack_m 연결** (`store`) | 권장 | 같은 구역 Rack_m만 |

### 2.7 출하 AMR (`amrRole: ship`)

| 링크 | 동작 |
|---|---|
| **출하 → 컨베이어** | 밀어 넣을 출하 벨트. 없으면 대기 포즈가 맞는 벨트 폴백 |
| **픽업 → 팔레트** | (필요 시) 담당 스테이션 |

### 2.8 고정 랙 (`rack`, `rackType` ≠ mobile)

| 링크 | 동작 |
|---|---|
| **출고 ← 팔레트/AMR** | 직접 입고 목적지 |
| **담당 랙 ← 지게차** | 그 지게차만 입고·출고. 링크 없는 랙은 “담당 없는 랙”으로 폴백 대상 |

### 2.9 이동식 랙 Rack_m (`rackType: mobile`)

| 링크 | 동작 |
|---|---|
| **담당 랙 ← 지게차** | `mobileRack` 지게차가 만재를 이 랙에 올림 |
| **담당 랙 ← AGV** | 이 랙을 견인 |

`enabled: false`면 적재·견인 대상에서 제외. 셀에 Rack_m이 없거나 비활성이면 서비스 지게차는 고정 랙 **직접 적재**로 폴백(담당 이동식만 연결된 경우는 대기).

### 2.10 도크·적치장 (`dock`)

| 링크 | 동작 |
|---|---|
| **출고 ← 팔레트/AMR** | 만재 도착 도크 |
| **빈 팔레트 회수 ← AMR** | 그 AMR용 빈 스택 |
| **빈 팔레트 회수 ← 지게차** | 지게차 빈 스택 |
| **회수 ← 트랜스퍼** | 리프트 빈 팔레트 적치 |

`dockRole`(palletSource / ship / unload / service / rackDrop / stage)은 **스톱 포인트·역할**이고, 링킹과 별개로 동작 위치가 정해진다.

### 2.11 스캐너 (`scanner`)

| 링크 | 동작 |
|---|---|
| **공급 ← 컨베이어** | 그 컨베이어 AMR이 이 스캐너에서 하역 |

### 2.12 레일 (`rail`)

| 링크 | 동작 |
|---|---|
| **공급 ← 컨베이어** | 그 컨베이어 AMR이 팔레트를 이 레일에 올림 |
| **분배 → 트랜스퍼** | 레일 끝에서 넘길 리프트. 없으면 끝점 가까운 리프트 |

### 2.13 트랜스퍼 리프트 (`transfer`)

| 링크 | 동작 |
|---|---|
| **분배 ← 레일** | 어느 레일에서 받는지 |
| **회수 → 지게차 / 적치장** | 내린 빈 팔레트 회수처 |

## 3. 폴백 요약

| 상황 | 링크 있음 | 링크 없음 + autoConnect on | autoConnect off |
|---|---|---|---|
| 로봇 박스/팔레트 | 링크 대상만 | reach·거리 | 링크 필수에 가깝게 동작 축소 |
| 팔레트 출고 | 링크 목적지만 | acceptGrade 통과 최근접 | deliver 없으면 출고 안 함 |
| AMR 픽업 | 링크 AMR만 | 유휴·근접 배정 | pickup 없으면 출고 대기 |
| 지게차 ↔ AMR | 링크 엄격(회수) | 셀·최근접 | 링크된 쌍만 |
| 지게차 ↔ 랙 | `store` 담당만 | 미할당 랙 | 담당만 |
| AGV ↔ Rack_m | `store` 이동식만 | 같은 셀 Rack_m | 연결분만이 안전 |
| 출하 AMR ↔ 벨트 | `handoff` | 대기 포즈 매칭 벨트 | 링크 우선 |

## 4. UI

- 편집 중 설비 디테일 **연결** 섹션: `LinkGuide` 체크리스트(역할별) + 현재 링크 목록·해제.
- 연결 모드에서만 장면 마커·점선 표시. 재생 중에는 숨김.
- 안내 문구 기준 클래스: 팔레트 AMR / 포크리프트 / AGV / 출하 AMR / 고정 랙 / 이동식 랙.
